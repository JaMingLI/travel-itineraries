操作參考｜手機上網與 eSIM 設定

📱 手機上網與 eSIM 設定

手機型號、方案與完成情況請在上方可編輯清單記錄。以下為通用操作參考，實際設定以手機與購買方案的說明為準。

購買前

  • 逐一確認兩人的手機型號、銷售地區版本是否支援 eSIM，以及有無電信業者鎖定；不支援時改用實體 SIM 或原門號漫遊。
  • 選擇覆蓋 11/14–11/21 全程的方案，確認「8 天」如何計算、效期從安裝／啟用／首次連網何時起算；不要未讀說明就提早開通。
  • 比較總流量、每日上限、降速條件、熱點分享限制、支援網路及客服方式。純數據方案通常沒有可接打電話的日本門號，訂位前先確認需求。
  • 建議兩人各有可獨立使用的網路，避免分開購物或一人手機沒電時完全失聯。方案尚未選購，費用待列入完整旅費。

出發前，在穩定 Wi-Fi 下準備

  1. 依方案指示決定是否預先安裝；將線路命名為「日本上網」和「台灣門號」。
  2. 保存安裝說明、APN（若需要）、訂單及客服資料；QR Code 可備存在另一台裝置，避免同一支手機無法直接掃描。安裝碼不要公開分享。
  3. 確認台灣門號是否需保留以收驗證簡訊，並查原電信業者的漫遊資格與通話、簡訊費率。
  4. 下載 USJ 官方 App、Google Maps、翻譯工具；保存住宿地址、當日路線與訂單，下載需要的離線翻譯語言。

抵達日本後

  1. 開啟日本 eSIM，將「行動數據」指定給日本線路。
  2. 日本線路是否開啟「數據漫遊」依供應商指示；台灣線路關閉數據漫遊，並檢查／關閉自動切換行動數據功能。
  3. 測試開啟網頁、Google Maps 和雙方通訊軟體；需要分享網路時也先測試熱點。
  4. 無法連線：先確認數據線路、方案是否生效、漫遊與 APN，再切換飛航模式或重開機。不要急著刪除 eSIM，部分方案無法重新安裝；透過機場／住宿 Wi-Fi 聯絡客服。

回台後把行動數據切回台灣門號，確認帳單與日本方案到期／續訂設定。參考：Apple 旅遊 eSIM 說明。Android 選單依品牌與版本不同。

操作參考｜USJ 當天操作清單

🎢 USJ 當天操作清單

  1. 出發前：兩人各選最想玩的設施，合併排出前三名；是否購買 Express Pass 依目標設施與預算決定，尚未代選。先查營業時間及設施停運公告。

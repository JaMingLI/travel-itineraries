操作參考｜手機上網與 eSIM 設定

📱 手機上網與 eSIM 設定

手機型號、方案與完成情況請在上方可編輯清單記錄。以下為通用操作參考，實際設定以手機與購買方案的說明為準。

購買前

  • 逐一確認兩人的手機型號、銷售地區版本是否支援 eSIM，以及有無電信業者鎖定；不支援時改用實體 SIM 或原門號漫遊。
  • 選擇覆蓋 11/14–11/21 全程的方案，確認「8 天」如何計算、效期從安裝／啟用／首次連網何時起算；不要未讀說明就提早開通。
  • 比較總流量、每日上限、降速條件、熱點分享限制、支援網路及客服方式。純數據方案通常沒有可接打電話的日本門號，訂位前先確認需求。
  • 建議兩人各有可獨立使用的網路，避免分開購物或一人手機沒電時完全失聯。方案尚未選購，費用待列入完整旅費。

出發前，在穩定 Wi-Fi 下準備

  1. 依方案指示決定是否預先安裝；將線路命名為「日本上網」和「台灣門號」。
  2. 保存安裝說明、APN（若需要）、訂單及客服資料；QR Code 可備存在另一台裝置，避免同一支手機無法直接掃描。安裝碼不要公開分享。
  3. 確認台灣門號是否需保留以收驗證簡訊，並查原電信業者的漫遊資格與通話、簡訊費率。
  4. 下載 USJ 官方 App、Google Maps、翻譯工具；保存住宿地址、當日路線與訂單，下載需要的離線翻譯語言。

抵達日本後

  1. 開啟日本 eSIM，將「行動數據」指定給日本線路。
  2. 日本線路是否開啟「數據漫遊」依供應商指示；台灣線路關閉數據漫遊，並檢查／關閉自動切換行動數據功能。
  3. 測試開啟網頁、Google Maps 和雙方通訊軟體；需要分享網路時也先測試熱點。
  4. 無法連線：先確認數據線路、方案是否生效、漫遊與 APN，再切換飛航模式或重開機。不要急著刪除 eSIM，部分方案無法重新安裝；透過機場／住宿 Wi-Fi 聯絡客服。

回台後把行動數據切回台灣門號，確認帳單與日本方案到期／續訂設定。參考：Apple 旅遊 eSIM 說明。Android 選單依品牌與版本不同。

操作參考｜機場銜接與行李

✈️ 機場銜接與行李

以下時間與每日20%緩衝時間軸同步，為這份行程的緩衝建議，不是航空公司櫃檯開放時間或最後報到期限。航廈、報到截止及行李額度仍須查看電子機票與華航通知。

11/14 去程｜CI152 09:45 起飛

  • 建議約 06:45 抵達桃園機場；住處出門時間需再依前往機場的交通方式倒推。
  • 13:20 抵達 KIX 後依序辦理入境、領行李、海關及上網測試，再前往南海車站。
  • 從南海電鐵關西機場站搭空港急行往難波，在天下茶屋站下車；空港急行是車種名稱，請找南海閘口。
  • 不預訂抵達當天下午的不可退活動；若班機或入境延誤，晚餐縮為住宿周邊簡餐。

11/21 回程｜CI173 19:00 起飛

  • 以 15:15 前抵達 KIX 出境航廈為規劃目標，若購物退稅量多則再提早。
  • 暫以 13:15 領行李並離開住宿作緩衝規劃；前一晚查南海班次、航廈與轉移時間後調整，不視為已查證時刻表。
  • 行李無法寄放時，優先退房後帶往機場；不要假設車站一定有可用的大型置物櫃。
  • 到機場先確認退稅商品查驗與託運的先後順序，完成必要查驗再依現場指示交運行李。

行李打包

  • 依票種確認每人託運件數／重量、手提尺寸／重量；購物後於 11/20 晚間先秤重。
  • 行動電源與備用鋰電池不放託運行李；容量、件數及機上使用限制依華航最新規範。藥品、證件、貴重物與充電線放隨身包。
  • 攜帶舒適步行鞋、分層衣物、輕便雨具、備用襪、充電器與行動電源；出發前一週再依大阪／京都預報調整衣物。
  • 查看充電器支援電壓與插腳，按需要準備轉接頭；不假設所有台灣電器都可直接使用。

官方：華航機場報到服務 · 華航危險品及電池規範

操作參考｜USJ 當天操作清單

🎢 USJ 當天操作清單

  1. 出發前：兩人各選最想玩的設施，合併排出前三名；是否購買 Express Pass 依目標設施與預算決定，尚未代選。先查營業時間及設施停運公告。
  2. 票券：Studio Pass 是入園門票；Express Pass 是指定設施的快速通關商品，購買時需核對內容與時段，不視為取代入園門票。
  3. App：安裝最新官方 App，預先登錄同行兩人的入園票券。主用手機保持連線，另一支保存票券備份並帶足電量。
  4. 入園後：依當日規定查看目標園區的入場整理券／抽籤券。部分園區可能需要指定入場資格，可由部分套票事先取得，或入園後透過官方 App 申請；數量有限，不保證可取得。
  5. 園內：按已取得的指定時段安排行程；園區入場資格不等於所有設施免排隊。保留用餐、休息與移動時間，不把前三名之外的項目排成硬性任務。
  6. 回程：離園前查看返回住宿的轉乘與末班車；原則不搭計程車，疲累時提早離園。

官方：USJ 電子整理券與園區入場說明。適用園區、發券狀況與快速通關內容依到訪日公告。

操作參考｜雨天、疲累與交通備案

☔ 雨天、疲累與交通備案

情況處理方式
京都和服日下雨前 2–3 天看預報，先問店家改期／取消與雨具規則。小雨縮短老街拍照、增加室內用餐休息；大雨優先安全。未確認所有訂單可變更前，不直接互換日期。
大阪城／北濱遇雨縮短公園與河畔步行，改以天守閣（依開放狀況）、咖啡與室內商場為主。
海遊館日下雨保留室內海遊館與晚餐，減少天保山戶外散步。
USJ 遇雨或設施停運依官方 App 調整至可開放項目與表演，不預設門票可以因下雨退款；攜帶雨衣及備用襪。
走累、餐廳久候每天可刪去最後一個非預約景點；餐廳候位超過兩人可接受時間就改附近簡餐，不跨區追店。
列車停駛或延誤先看站方公告與替代鐵道路線；回程日取消補貨、提早去機場。涉及航班風險時立即聯絡航空公司，不等到最後一班可行列車。

離線資料只能備查，不能提供即時轉乘；每天出門前用連線導航確認班次。11/16 京都早出門，早餐與飲水前一晚先準備。

操作參考｜保險、藥品與緊急資料

🩹 保險、藥品與緊急資料

  • 投保狀態待確認；檢查兩人的海外醫療、旅遊不便、班機延誤及行李保障範圍、除外事項與理賠文件需求。
  • 手機離線存保單號碼、24 小時救援聯絡方式、緊急聯絡人及住宿地址；兩人互相知道資料位置。
  • 攜帶足量常用藥、過敏與用藥清單，保留原包裝或處方資料；特殊藥品需另查日本攜入規定，不直接假設可帶入。
  • 日本緊急電話：110 警察；119 消防／救護。純數據 eSIM 不能當作一般電話服務，必要時請現場人員協助撥打並清楚提供位置。

官方：日本觀光局緊急資訊 · 旅遊保險與就醫資訊
